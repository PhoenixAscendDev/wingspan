# Wingspan – Phoenix Ascend’s Agile Delivery Toolkit

**Wingspan** is a lightweight planning and product leadership system developed by [Phoenix Ascend](https://www.phoenixascend.com).  
It’s built for teams who want to move fast *and* stay aligned—with clarity, consistency, and care.

This toolkit was forged in the real-world challenges of software delivery, legacy modernization, and Agile transformation. It’s not a theory—it’s a proven field guide.

---

## 🧭 What's Inside

Each tool in Wingspan was designed to answer a specific problem product leaders face in the wild:

### 📌 Templates
| Tool | Purpose |
|------|---------|
| **OPPM (One Page Product Management)** | Align scope, priorities, and timelines—on a single page. |
| **Compass** | Tie MVPs to delivery milestones across real-world constraints. |
| **Hi-Lo Gauge** | Assess product health, technical debt, and business readiness. |
| **MVP Canvas** | Map the user journey, pain/gain analysis, and prioritization. |
| **Sanity Check Template** | Prep your team for smooth, confident releases. |

### 🛠 Strategy Docs
- **The Loading Dock Strategy**  
  A DevOps model for when a product is *actually* ready to ship—built on trust between dev and ops.
